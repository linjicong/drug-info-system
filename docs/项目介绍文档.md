# 药品信息管理系统项目介绍

## 一、项目概述

药品信息管理系统是一个面向药品数据采集、整合、追踪与分析的业务系统。项目聚焦广东区域两类权威数据源：

- 广州药品采购平台（GPO）公示数据
- 广东省医保局挂网药品公示数据

系统通过自动化抓取与统一数据建模，形成“采集-整合-追踪-导出”的闭环，支撑业务团队在价格比对、药品监控、历史变更分析等场景中的日常工作，减少人工检索成本并提升数据时效性。

## 二、建设目标

- 打通双平台药品数据，建立统一查询入口
- 支持药品数据按条件筛选、分页浏览与明细查看
- 支持一键导出 Excel，满足线下分析和汇报使用
- 建立台账追踪机制，对重点药品进行长期监控
- 沉淀历史快照，支持价格波动和字段变化分析

## 三、核心功能模块

### 1）广州药品采购平台模块（`/gz`）

- 抓取广州公共资源交易中心药品采购公示数据
- 支持手动抓取、进度可视化、查询筛选、数据导出
- 支持产品名称、医保编码、生产企业等字段组合筛选

### 2）广东省医保局模块（`/pubonln`）

- 抓取广东省医保局挂网药品公示数据
- 与广州模块保持一致的检索与导出能力
- 便于业务人员在同一系统内横向比对两个来源

### 3）药品汇总模块（`/merged`）

- 对双平台数据进行统一字段整合与去重归档
- 采用五字段联合去重规则：产品名称 + 医保编码 + 生产企业 + 最小包装数量 + 最小包装单位
- 支持全量手动合并、任务进度展示、调度状态查看
- 支持导出当前筛选结果，服务于对比分析与汇总汇报

### 4）台账追踪配置模块（`/ledger/track`）

- 维护重点监控药品清单（新增、编辑、删除、批量导入）
- 支持模板下载 + Excel 导入，提高配置效率
- 提供“匹配状态”与“未匹配原因提示”，便于纠偏

### 5）台账历史查询模块（`/ledger/history`）

- 查询重点药品在时间维度上的历史快照
- 支持日期区间检索、分页、当前查询导出
- 支持“每周一导出”并高亮价格/挂网时间变化，便于周期性分析
- 支持手动触发当日台账快照生成，满足临时业务需要

## 四、业务流程（端到端）

1. **数据采集**：从双平台抓取药品公示数据  
2. **数据入库**：分别写入各自数据表并保留原始关键字段  
3. **数据整合**：按联合主键规则进行汇总去重，落地为统一汇总表  
4. **监控配置**：维护业务关注药品，形成监控清单  
5. **历史沉淀**：按日生成台账快照，记录价格与关键信息变化  
6. **查询导出**：面向业务筛选、比对、导出，支撑分析与汇报

## 五、技术架构与实现方案

### 前端与应用层

- 框架：Next.js 16（App Router） + React 19 + TypeScript 5
- UI：shadcn/ui + Radix UI + Tailwind CSS 4
- 页面结构清晰，按业务模块分路由组织
- 通过统一的查询、分页、筛选交互，降低使用门槛

### 服务与数据层

- 主要接口采用 Next.js API Route 组织
- 业务服务层集中在 `src/lib`（如抓取服务、汇总服务、台账服务）
- 数据访问使用 Supabase 客户端，支撑结构化存储与检索
- 台账服务支持匹配状态计算、快照生成、时间区间查询

### 任务与进度机制

- 手动触发抓取/合并时提供实时进度反馈
- 支持轮询任务状态，展示运行阶段与完成情况
- 支持调度配置状态查看，便于运维与业务联动

## 六、项目亮点

- **双源整合**：打破平台数据孤岛，形成统一视图
- **规则去重**：联合字段去重，提升数据可用性与准确性
- **追踪闭环**：从监控清单到历史快照，形成持续追踪能力
- **变化识别**：周维度导出并高亮变化，快速识别风险点
- **业务友好**：检索与导出流程简洁，适合非技术人员使用

## 七、当前价值与应用成效

- 降低人工检索与多平台切换成本
- 提升药品价格信息获取效率与时效
- 为采购、医保对比、合规复核等场景提供数据支撑
- 通过历史台账沉淀，增强决策可追溯性

## 八、后续优化方向

- 引入更细粒度的异常告警（如价格突变、匹配失败率上升）
- 增加自动化质量校验与数据健康看板
- 支持更多数据源接入，扩展跨区域对比能力
- 完善权限与审计能力，满足更严格的业务治理需求
